# Trabalho Final - Assunção Gonçalves

Este artefacto digital em p5.js é uma grelha de módulos geométricos (círculos, meia-lua e barra) em várias cores como menta, bege e mostarda, que reagem ao movimento do rato. Os módulos crescem quando o rato se aproxima e encolhem à medida que se afasta, e rodam a 90 graus a cada clique, por isso cada visita gera um padrão diferente. O input é a posição do rato e o clique, com o random() a sortear o tipo, a rotação e a cor de cada módulo no início. A expressão são padrões que se repetem e rodam, numa paleta reduzida de três cores sobre um fundo branco, e o output é uum artefacto interativo que gera composições modulares, usáveis como grafismmo ou textura. No projeto (com)Forma, estes módulos podem servir ao conceito modular como peças de um bule que se combinam e rodam em configurações diferentes. Na realização deste trabalho, recorri aos exemplos dados pelo professor na Aula 4, e utilizei a inteligência artificial Claude como apoio para estruturar o código base, explicar alguns funcionamentos e corrigir erros de sintaxe. Fiz, testei e fui adaptando o código. Experimentei também um input de som, mas acabei por abandonar porque não estava a conseguir que funcionasse.
